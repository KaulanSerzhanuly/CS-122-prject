# Video Assets

This directory contains video assets for Snake of Despair.

## Placeholder Files

The game will generate fallback video sequences if these files are missing:
- `screamer_clip.mp4` - Short screamer video
- `tension_build.mp4` - Tension building sequence

## Asset Requirements

- Format: MP4 or AVI
- Duration: 1-3 seconds maximum
- Resolution: 320x240 to 640x480
- Frame rate: 24-30 FPS
- File size: Keep under 5MB

## Accessibility

For reduced scare mode:
- Avoid rapid cuts
- Use gentle transitions
- Mute audio or use low volume
- Avoid strobing effects

## Licensing

All placeholder assets are generated at runtime and are safe to use.
For production, replace with properly licensed video files.
