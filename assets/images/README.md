# Image Assets

This directory contains image assets for Snake of Despair.

## Placeholder Files

The game will generate fallback images if these files are missing:
- `flash_overlay.png` - Flash effect overlay
- `screamer_image.png` - Screamer visual effect
- `overlay.png` - General overlay effect

## Asset Requirements

- Format: PNG with transparency support
- Size: 100x100 to 400x400 pixels
- Color depth: 32-bit RGBA
- Transparency: Alpha channel supported

## Accessibility

For reduced scare mode, use muted colors and avoid:
- High contrast flashes
- Rapid color changes
- Bright white flashes

## Licensing

All placeholder assets are generated at runtime and are safe to use.
For production, replace with properly licensed image files.
