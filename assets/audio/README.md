# Audio Assets

This directory contains audio assets for Snake of Despair.

## Placeholder Files

The game will generate fallback audio if these files are missing:
- `scream.wav` - Screamer audio effect
- `beep.wav` - General notification sound
- `tension.wav` - Tension building sound

## Asset Requirements

- Format: WAV, OGG, or MP3
- Sample rate: 22050 Hz or higher
- Channels: Mono or Stereo
- Duration: Keep under 2 seconds for performance

## Licensing

All placeholder assets are generated at runtime and are safe to use.
For production, replace with properly licensed audio files.
